# 上游交互与阅读体验迁移

更新日期：2026-10-28。基于 `main` 的 `0380e8f`（包含 PR #195），保留此前本地改动。

## 已实现

- 文章卡片与页头共享过渡；慢请求在 HTML 到达后才捕获画面，支持取消、错误清理、减少动态效果和普通转场回退。按完整 permalink 匹配，忽略导航查询参数。
- 按浏览器历史条目恢复滚动位置，兼容同一个 URL 多次出现。
- 手机菜单与右侧栏互斥打开，支持 Esc、焦点返回、键盘焦点约束和断点切换。固定面板依据分页及 visualViewport 避让；宽屏页脚位于侧栏轨道之后。
- Embla 轮播支持按钮、拖拽、循环、自动播放、暂停和方向键；普通纵向滚轮与缩放手势保持浏览器行为，Shift 滚轮横向操作。手动暂停不会被拖拽或悬停退出覆盖。
- 普通代码块支持语言/文件名、行号、完整源码复制、自动换行及超过 20 行时折叠。保留原始代码 DOM；已有 `shiki-code` 组件由插件负责。
- 表格支持独立滚动、吸顶表头、自动换行与横向滚动切换，保留表格、caption、thead 的原始语义。
- Mermaid 在接近视口时动态加载，等待字体，串行处理全局主题配置；支持暗色重绘、原始尺寸、适应宽度、查看源码和错误重试。已有插件渲染的 SVG 不会被接管。
- 修复 ESLint 9 配置，并提供跳到正文入口、减少动态效果处理及交互回归测试。

代码按职责位于 `src/modules/reading/`、轮播/抽屉模块及 `src/swup/`。编辑器生成的特殊内容可在父元素加 `data-no-reading-enhance` 跳过主题阅读增强。

## 使用方式

保留现有主题配置。文章共享过渡需要在“自定义”中启用 Swup；轮播继续使用后台配置的首页组件与文章列表。普通代码块、表格及可识别的 Mermaid 原文自动增强。

多站点为可选适配。无该插件时菜单、热门/最新文章使用 Halo 原生 Finder；主菜单仍可从“侧边栏头部”选择，备案信息使用主题配置。以上迁移功能无需安装多站点插件。

- 现有 Chrome 连接中验证共享过渡及清理、返回滚动恢复（误差 1px）、抽屉互斥/Esc、轮播按钮和方向键、代码复制原文、换行/折叠、表格两种模式、Mermaid 成功/失败回退和暗色重绘。

暂停/指针释放、visualViewport 计算和减少动态效果覆盖了回归测试；实际触摸拖拽与软键盘尚未在 iOS/Android 真机验收。现有构建仍提示 Browserslist 数据较旧、DaisyUI 的 `@property` 优化警告及大型异步图表分包提示。

## 构建与复验

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm build
```

安装 `dist/theme-clarity-1.6.16.zip` 到兼容 Halo，依次验证首页轮播、文章返回、手机抽屉和包含代码/表格/图表的文章。发布验证记录见 `docs/releases/1.6.16.md`。
