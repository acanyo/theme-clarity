# Clarity 1.6.17

发布日期：2026-10-29。兼容 Halo >= 2.26.0。

## 更新内容

- 装备页升级为展架布局，完整展示设备图片，名称、规格和使用说明无需悬停即可阅读。
- 新增展架与清单两种视图，支持切换并记住浏览偏好。
- 优化装备详情，支持本页装备前后浏览、左右方向键、Esc 关闭和关闭后焦点返回。
- 新增单件装备分享链接，保留分组和分页信息，打开链接即可直达对应装备详情。
- 优化手机与深色模式下的展示，完善长说明滚动、缺图回退和空状态；长内容中关闭按钮与底部操作保持可见。
- 适配 Swup 页面切换，保留装备分组、分页及浏览器返回操作。

使用装备页需安装并启用「装备管理」插件；升级后沿用已有装备和分组数据。
