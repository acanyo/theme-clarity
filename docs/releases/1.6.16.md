# Clarity 1.6.16

发布日期：2026-10-28。兼容 Halo >= 2.26.0。

## 更新内容

- 增强文章卡片与页头的共享过渡，按浏览器历史条目恢复返回位置，兼容减少动态效果设置。
- 首页轮播改用 Embla，支持拖拽、循环、播放/暂停、方向键和 Shift 滚轮；恢复原版居中布局、两侧卡片预览及圆角矩形箭头。
- 优化手机菜单、右侧栏的互斥打开、Esc 关闭、焦点管理和底部面板避让。
- 普通代码块增加文件名、语言、行号、复制、换行和长代码折叠；表格支持滚动与换行切换、吸顶表头。
- Mermaid 按需加载，支持深色重绘、原始尺寸/适应宽度、查看源码及错误重试，并兼容已有插件渲染内容。
- 右侧栏新增热门文章、最新文章组件；搜索入口支持配置开关。
- 修复多站点插件缺失时的菜单、页脚与文章组件调用，提供 Halo 原生数据回退。
- 恢复文章上/下篇导航和排序配置，保留分类浏览上下文、键盘切换及共享过渡。
- 包含自上一正式版以来已合并的瞬间海报、友链可访问性状态、互动增强接入和插件缺失提示等适配。

本次未宣称完成原版全部功能同步。故事/技术文章配置、列表筛选排序、专属侧栏等后续差异见 [功能对照](../upstream-feature-audit.md)。
