# 装备展架

2026-10-29 将装备页从图库瀑布流调整为个人装备展架，继续使用装备插件的名称、规格、说明、图片、链接和分组数据。没有增加价格、评分、购买日期或使用状态等需要额外维护的字段。

## 页面行为

- 展架使用统一的图片区域与浅层台沿；图片完整显示，名称、规格和说明无需悬停即可阅读。
- 支持展架/清单两种视图，浏览器记住展示偏好；存储不可用时仍能切换。
- 分组和分页继续由装备插件查询；没有只在当前页模拟全站筛选。
- 详情支持本页装备前后浏览、左右方向键、Esc、点击背景关闭、关闭后焦点返回与原生模态焦点约束。
- 复制的单件链接包含当前分组、分页和装备标识，打开链接可以直接查看该装备。
- 长说明可滚动阅读，关闭及底部操作保持可见；无图和图片加载失败时显示占位，空字段隐藏。
- 相关链接只接受 HTTP/HTTPS，文本均按文本展示；适配深色模式和减少动态效果偏好。

模板位于 `templates/equipments.html` 和 `templates/modules/equipments/detail.html`；视图与详情交互分在 `src/modules/equipments/`，样式分在 `src/styles/equipments/`。首次加载和 Swup 切换均初始化，初始化前清理旧监听与模态状态。

## 本地验证

- 构建、ESLint、14 项已有回归测试和 diff 检查通过。
- Docker Halo 2.27.0 + 装备管理 1.1.1 实际安装主题包，复查装备页、分组、分页、空状态和共享布局。
- 本地演示的七件装备、图片及说明来自现有公开装备页，未把样例数据写入主题模板。边界验收临时添加的单条、长文本、空分组和失效图片数据已清理。
- 无窗口 Chrome 实测展架/清单及偏好记忆、详情前后切换、首尾禁用、方向键、Esc、焦点返回、剪贴板链接及直接打开、真实分页、Swup 往返、缺图和失效图片。
- 1440×1050、768×1024、390×844、320×740、844×390 无页面横向溢出，弹窗保持在视口内；深色与浅色截图复查通过。
- 长说明滚动到底时关闭与底部操作仍可见。iOS/Android 真机触摸尚未验收。
